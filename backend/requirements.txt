# 【2026-08-06】>=10.0,<11.0 から引き上げ。理由は 2 つ。
#
# 1. cp314 wheel が無かった
#    Pillow 10.4.0 の wheel は cp313 までで、Python 3.14 では sdift (46MB) を
#    落として C コンパイルに落ちる。本番 Render は libjpeg ヘッダを持つので
#    通っていたが、GitHub の ubuntu runner には無く CI が落ちた:
#      "The headers or library files could not be found for jpeg"
#    cp314 wheel を持つ最小版は 11.3.0。
#
# 2. 10.4.0 に既知脆弱性が 30 件超あり、大半は 12.2 / 12.3 でしか直っていない
#    (Image.paste()/crop() のヒープ書き込み、ImageCmsTransform.apply() の
#     境界外書き込み、PSD/PDF/FITS/TGA パーサ由来の DoS 等)。
#    そのため 11.3 ではなく 12.3 を下限にする。
#
# 影響範囲は狭い: コードに `from PIL import` は 1 件も無く、Pillow を通るのは
# Announcement.image (ImageField) の検証だけ。これは Django admin 専用 + MFA 保護。
# お問い合わせ添付 (views/health.py) はサイズと content-type のみで検証しており
# Pillow を通らない。
Pillow>=12.3,<13.0
