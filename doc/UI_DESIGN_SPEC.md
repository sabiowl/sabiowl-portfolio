## 2. コンポーネント仕様

### 2.1 HabitCard

```
┌─────────────────────────────────┐
│ [▌] [🏃] 毎朝ランニング   [🔥 7] │  ← ドラッグハンドル / アイコン / ストリーク
│      Normal ⚡  daily           │  ← 難易度バッジ / 頻度
│      ████████████░░░░ 80%       │  ← プログレスバー
│      🌟 達成: 15日              │  ← ベストストリーク
│                         [✓ 完了] │  ← アクションボタン
└─────────────────────────────────┘
```

**スタイル仕様:**
- 左ボーダー: 3.5px solid `{難易度カラー}`
- 背景: `{難易度背景カラー}` at 40% opacity（完了時は白）
- 完了済みカード: テキスト `line-through`、opacity 0.6、背景 `#F0FFF4`
- プログレスバー: 進行中=`#534AB7` / 完了=`#4CAF50`、高さ 6px、radius 3px

**インタラクション:**
- タップ（チェック）: 0.15s ease、チェックマーク表示 + 緑フラッシュ（200ms）
- 長押し（並び替え）: 0.2s で影 Level 3 に昇格、振動フィードバック（haptic light）
- スライドリリース後: 0.25s ease-out でドロップ

/* 通常状態 */

### 2.4 LevelUpDialog（Flutter）— 改善版

現状から追加すべき要素:

1. **パーティクル演出:** 星のパーティクルを CustomPainter で 8〜12 個放射
   - 初速: 80〜150dp/s、ランダム方向、0.6s で消える（fade + scale down）
2. **ステータスポイント割り当て UI:** ダイアログ内でそのままポイント振り分けができる
   ```
   ✨ LEVEL UP!
   Lv. 12
   ─────────────────
   ステータスポイント配分 +3
   [💪 運動力] [+] 0 [-]
   [📖 学習力] [+] 0 [-]
   [🧘 精神力] [+] 0 [-]
   [💧 健康力] [+] 0 [-]
   ─────────────────
   残り: 3 ポイント
   [確定して続ける]
   ```
3. **背景ブラー:** `BackdropFilter(filter: ImageFilter.blur(sigmaX: 4, sigmaY: 4))`

### 3.2 習慣チェック完了フロー

```
[タップ] 
  → チェックマーク表示（即時）
  → カード背景フラッシュ: #4CAF50 → 元色（200ms ease）
  → EXP バー増加アニメーション（400ms ease-out）
  → EXP が MAX 超えた場合: LevelUp 演出へ
  → ストリーク +1 表示（🔥 数字がポップする scale 1.0→1.3→1.0、300ms bounce）
  → Haptic feedback: light impact

[レベルアップ時の追加演出]
  → EXP バーが 100% に達する（400ms）
  → バーが白くフラッシュ（100ms）
  → LevelUpDialog 表示（600ms elasticOut）
  → パーティクル放射
  → Haptic feedback: heavy impact
```

---

### 3.3 ガチャ演出フロー（3タップ方式）

```
[チケット選択]
  → カード種別インジケーター点灯（pulse animation 2s loop）

[タップ1 — 準備]
  → カード震え（gShake1、0.3s）
  → 霧エフェクト発生（opacity 0→0.6、0.5s）
  → Haptic: medium

[タップ2 — 開封]
  → クラックアニメーション（0.4s）
  → フラッシュ白（100ms）
  → Haptic: heavy
  → SE: 開封音（想定）

[タップ3 / 自動 — 結果表示]
  → カード floatIn（0.5s decelerate）
  → レアリティ別グロー点灯（0.3s）
  → SR/SSR: 追加演出（rainbow border loop / gold drop particles）
  → Haptic: heavy（SSR のみ連続 3 回）

[閉じる]
  → 結果カード fadeOut（0.3s）
  → チケット枚数更新
```

## 4. 画面別 UX 仕様

### 4.1 ホーム画面（優先度: ★★★）

**情報の優先順位:**
1. 今日の習慣リスト（最重要 — 画面の 70% 以上）
2. EXP バー・レベル（モチベーション）
3. ガチャチケット枚数（報酬の見通し）
4. Sabi のメッセージ（感情的な繋がり）

**改善案:**
- ヘッダーの「ダイヤ残高 + チケット + モード」を 1 行に圧縮 → 高さ 56px 以内に
- Sabi メッセージは折り畳み状態をデフォルトに（タップで展開）
- 「習慣 0 件」時は空状態 UI を表示（現状は空リストのまま）

**タブ切り替えアニメーション:**
- アクティブタブ: アンダーライン（3px、プライマリカラー）が slide（300ms ease-out）
- コンテンツ: fade（200ms）。スライドは不要（タブは左右並列ではなく独立コンテンツ）

---

### 4.2 習慣追加・編集画面（優先度: ★★☆）

**フォームのグルーピング（現在バラバラ → セクション化）:**

```
─── 基本情報 ─────────────────
  習慣名
  カテゴリ  [🏃 運動] [📚 学習] [💧 健康] [🧘 メンタル]
  メモ（任意）

─── 目標設定 ─────────────────
  タイプ    [count] [checklist]
  頻度      [daily] [weekly] [monthly]
  リセット  [毎日] [毎週] …

─── 難易度 ───────────────────
  [🌱 Easy] [⚡ Normal] [🔥 Hard] [👑 Legendary]
  獲得EXP: 30 / 回（プレビュー表示）

─── オプション ───────────────
  公開設定  [ON / OFF]
```

**難易度選択:** 横並びの選択チップ（選択時: カラー背景 + 白文字、非選択: 枠線のみ）

---

### 4.3 ガチャ画面（優先度: ★★★）

**チケット種別インジケーター:**
- 選択中チケットのカード（Daily/Weekly/Monthly）が前面に浮く演出（scale 1.05 + shadow Level 2）
- 枚数が 0 の場合: カードを 40% dim + 「チケットなし」テキスト

**演出レベル:**
| レアリティ | 演出 |
|---|---|
| N | カード flip（横回転 0.5s）|
| R | カード flip + 青い光（0.8s）|
| SR | flip + 紫グロー + 星パーティクル（1.2s）|
| SSR | flip + 金グロー + 金ドロップ + レインボーボーダー loop（2s）|

**ピティカウンター視覚化:**
- プログレスバー形式（現在回数 / ピティ上限）
- 残り 5 回以内: バーが赤くなる + テキスト「あと N 回で SR+ 確定！」
