# 概要
- 名前は「フェイ」
- アプリ「SabiOwl」の冒険モードのキャラクター
- 主人公と旅の途中で合流し、仲間になる
- 森の山小屋で自足自給の生活をしていた。主人公と会う時期に、森の植物が枯れやすくなる事象で困っていた。原因の人物を倒し、他の森も助けたい思いで仲間になる
# 特徴
- 男性。18~22歳くらい
- 緑色の目
- 茶色の髪
- 一人称は「ぼく」
- 森と弓兵のコスチューム
- 料理がすごい上手い
- 自身は味音痴で、美味しい料理も不味い料理も基本は美味しいと言い、本当にそう感じている
- 主人公に同伴する理由は、世界中の森を助けたいから、その根本原因を解決するため
- 主人公が選択できるキャラ
- 柔和な性格で、人の痛みに寄り添える
- 弓の精度は狙撃の名手レベル
- 家庭的なことは全て完璧に遂行できる
