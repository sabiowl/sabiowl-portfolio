# キャラデザイン
![[chara_f_knight_2.png]]
# 概要
- 名前は「ベアトリス」
- アプリ「SabiOwl」の冒険モードのキャラクター
- 主人公と旅の途中で合流し、仲間になる
- 昔、とある王国の護衛騎士だったが、遠征中に王国が原因不明の消滅をし、そこから行き場もなく雇われの傭兵として過ごしていた
# 特徴
- 女性。20~24歳くらい
- 紫色の目
- 赤色の髪
- 一人称は「わたし」
- 騎士のような鎧のコスチューム
- 料理が下手
- 主人公に同伴する理由は、自身の王国が消滅した原因を調べるため
- 主人公が選択できるキャラ
- 冷静で誠実。プライドが高そうな口調だが、納得すれば柔軟に対応する臨機応変さを持ち合わせている
- 家庭的なことになると、ポンコツな姿を見せる
